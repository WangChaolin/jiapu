02

导出 GEDCOM

将成员、家庭、关系、日期、地点、备注与照片映射为标准标签；兼祧、过继等本地扩展关系附兼容性说明。

导出范围标签映射照片与备注文件预览保存文件
标准兼容范围
  • INDI / FAM 个人与家庭记录
  • NAME / SEX / BIRT / DEAT / BURI 等常用标签
  • DATE / PLAC / NOTE / OBJE / SOUR 事件与来源
  • UTF-8 与常见 ANSI 中文编码识别
本地扩展关系

生 / 养 / 继 / 嗣 / 兼祧父母关系尽量映射到 PEDI / ADOP / FOST 等标准标签；无法完整表达的关系保留备注并生成兼容性报告。

安全与回滚

导入采用事务执行，失败整体回滚；成功后记录导入批次并支持撤销。GEDCOM 仅作为数据文本解析，不执行任何脚本。

下一步建议：先完成 GEDCOM 导入/导出，再推进自定义皮肤。云同步仍不进入当前迭代。
