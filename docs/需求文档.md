## 2. 功能需求

优先级定义：P0 = 首期必须（已完成）；P1 = 首期增强（已完成）；P2 = 后续迭代（已确认，GEDCOM 已完成）。

### 2.1 家谱成员录入（P0）

- 成员字段：
  - 基本信息：姓名、性别（男 / 女 / 未知，**男女完全平等，女性成员同样可作为世系节点向下延续后代**）、字 / 号、出生日期、卒日期、在世状态、照片、生平简介、备注
  - **日期支持公历与农历双制**：录入时选择历法，农历以干支年 + 月 + 日（如“辛卯年五月初六”）存储，展示时公历农历并列
  - 行第（兄弟姐妹中排行）、世代（第几世，自动推导 + 可手动修正）
- 亲属关系：
  - 父母类型：**生父 / 生母、养父 / 养母、继父 / 继母、嗣父 / 嗣母（过继）、兼祧父 / 兼祧母**
  - 过继：记录本生父母与嗣父母双系关系，世系图上以虚线区分
  - 兼祧：一子承两房，允许同时挂接主承父系与兼祧父系，标记主承关系；世系与 PDF 中均标注“兼祧”
  - 配偶：支持多任配偶（原配、继配等），记录婚配状态；配偶双方互相挂接
  - 子女：支持排序；同一对父母的子女自动归组
- 录入方式：表单录入 + 快速连续录入（“保存并录下一位”）；从任意成员出发“添加父亲 / 母亲 / 配偶 / 子女”
- 成员管理：搜索（姓名 / 字辈 / 支系）、编辑、删除（软删除，可恢复 / 撤销）、重复成员提示
- 成员列表：加高卡片区域，生卒、父母 / 配偶 / 子女、其他信息与生平直接内联展示，去掉独立右侧详情面板
- 校验：关系环路检测（禁止出现自己是自己祖先等非法关系）；兼祧 / 过继关系完整性提示

### 2.2 字辈管理（P0）

- 字辈序列维护：按“字辈诗”录入（如“国正天心顺，官清民自安”），逐字对应世代
- 支持全家谱统一字辈，也支持按支系各自字辈
- 字辈与世代对照表展示、编辑、插入 / 删除字（后续世代自动顺延）
- 录入成员时按当前世代自动推荐字辈用字；姓名与字辈不符时给出提示（可忽略，不强制；母系外姓成员不校验）

### 2.3 支系管理（P0 / P1）

**P0 已实现**
- 支系（房）树：以始祖或任意成员为根划分支系，支系可多级嵌套
- 支系属性：名称（如“长房”“二房”）、开基祖、排序、简介
- 成员归属：默认按父系自动推导所属支系，允许手动调整；兼祧成员可标注双重房支归属
- 按支系筛选成员、统计人数

**P1 增强**
- 支系合并、拆分、成员迁移，详见 2.11.1

### 2.4 导出 PDF · 多排版模式（P0 / P1）

首期三种排版（P0，已实现）：

1. **宝塔式吊线图**：世系自上而下如宝塔展开，连线表达父子关系，配偶并列，过继 / 兼祧虚线标注
2. **欧式横表（五世一表）**：表格横排，每表五代，表间世代衔接，适合世系总览
3. **苏式垂珠体（竖排）**：竖排右起，世代为列、人名为珠，传统线装书风格

通用能力：
- 导出范围：整谱 / 指定支系 / 指定世代区间
- 页面设置：纸张（A4 / A3 / B5 / Letter）、横竖向、页边距、正文字体字号
- 自动编排：封面（谱名、堂号、修谱时间）、目录、字辈对照页、页眉页脚（谱名 + 页码），均可选
- 中文字体嵌入，保证任何机器打开不乱码；导出前预览
- 当前采用 pdf-lib 矢量输出，不依赖系统打印组件

P1 新增排版：
- 人物传记式、名录简表式，详见 2.11.2、2.11.3

### 2.5 成员关系图谱（P0 / P1 / P2）

**P0 已实现**
- 交互式世系树：缩放、平移、按支展开 / 折叠
- 视图模式：全谱图 / 以某成员为中心的祖先视图 / 后代视图
- 节点展示：姓名、生卒年、世代、头像（可选）；单击查看详情，双击折叠 / 展开
- 配偶并列显示、多任配偶区分；子女按行第排序；过继 / 兼祧以虚线 + 标注区分
- 搜索定位：输入姓名自动跳转并高亮
- 当前布局：纵向树

**P1 / P2**
- P1：横向树布局、PNG 导出，详见 2.11.4、2.11.5
- P2：扇形 / 环形布局，详见 2.12.3

### 2.6 数据本地化存储（P0；云同步暂不排期）

- 本地存储：SQLite 数据库 + 本地照片目录，存放于用户数据目录，完全离线可用
- 每份家谱独立一个数据库文件，便于拷贝与迁移
- 数据库启用 WAL，写入使用事务；异常退出不丢已提交数据
- 云同步本期**不实现、不排期**，仅保留架构扩展点：
  - 主键使用 UUID，记录 updatedAt 版本号与软删除标记
  - 数据访问层抽象，保留 change_log 变更日志
  - 不承诺 WebDAV、自建同步服务或特定同步协议
- 后续如启动云同步，须单独进行需求确认、安全设计与数据迁移评审

### 2.7 数据备份与恢复（P0）

- 手动备份：一键将数据库 + 照片打包为单个备份文件（`.zip` 封装，含格式版本清单）
- 自动备份：每次启动 / 每日首次写入时自动备份，保留最近 N 份（默认 10，可配置）
- 恢复：选择备份文件 → 校验完整性 → 恢复前自动备份当前数据 → 还原
- 备份文件可跨机器拷贝恢复
- 通用格式导入 / 导出（JSON）
- GEDCOM 兼容为 P2，详见 2.12.1

### 2.8 多家谱管理（P0）

- 家谱列表页：创建、打开、重命名、复制、删除（删除需二次确认 + 建议先备份，支持撤销）
- **同时仅打开一份家谱**，打开新谱即切换当前谱
- 每份家谱数据完全独立：成员、字辈、支系、导出设置、皮肤
- 家谱属性：谱名、姓氏、堂号、始祖、修谱人、修谱时间、简介
- 启动进入家谱列表 / 最近打开

### 2.9 界面皮肤切换（P0 / P2）

- 内置主题 ≥ 3 套：浅色现代、深色、古典中国风（宣纸底色 + 赭石 / 墨色点缀），另提供“跟随系统”
- 即时切换无需重启；全局默认 + 可按家谱单独记忆
- 基于 CSS 变量的主题机制
- P2：自定义主题，详见 2.12.2

### 2.10 安装目录与数据目录自定义（P0）

- **安装目录可自定义**：NSIS 安装包采用非一键模式（`oneClick: false` + `allowToChangeInstallationDirectory: true`），安装向导中用户可自由选择安装路径；默认 per-user 安装，无需管理员权限
- **数据存储目录可自定义**：
  - 默认数据目录：`%APPDATA%/家谱管理软件/genealogies`
  - 设置页提供“更改数据目录”：选择新目录 → 校验可写 → **迁移已有家谱数据**（复制库文件与照片到新目录，原数据保留不删除）→ 切换生效
  - 引导配置 `config.json` 固定存放于 `%APPDATA%/家谱管理软件/`，不随数据目录迁移
  - 每份家谱一个独立子目录：`<数据目录>/<家谱ID>/genealogy.db` + `photos/`
  - 数据目录不可写 / 不存在时给出明确错误提示，不静默回退

### 2.11 P1 详细需求

#### 2.11.1 P1-1 支系合并、拆分与成员迁移

- 支系合并：支持两个或多个支系合并到目标支系
- 合并前展示影响范围：成员数、子支系数、关系数、开基祖变化
- 合并后保留全部成员及亲属关系，成员归属、人数统计、PDF 支系范围同步更新
- 支系拆分：以指定成员为新开基祖，将其所属子孙支系拆分为新支系
- 成员迁移：支持单个或批量成员调整所属支系
- 约束：不允许把支系合并到自己的后代支系；同名支系提示但不强制禁止
- 操作需二次确认，事务化执行，失败可回滚；支持撤销

验收标准：合并、拆分、迁移后成员和关系无丢失，支系统计正确，重新打开家谱后结果一致。

#### 2.11.2 P1-2 PDF 人物传记式排版

- 导出范围：整谱、指定支系、指定世代、勾选成员
- 每位成员独立成篇，包含姓名、字、号、性别、世代、生卒、父母、配偶、子女、支系、居地、葬地、照片、生平
- 长传记自动分页，标题与人物信息不悬空，照片不变形
- 可选封面、谱名、堂号、修谱时间、页眉页码
- 复用现有纸张、方向、页边距、字体字号设置

验收标准：长传记跨页无内容丢失，图片和中文正常，预览与导出结果一致。

#### 2.11.3 P1-3 PDF 名录简表式排版

- 每行一名成员，字段可选：姓名、性别、世代、字辈、支系、生卒、父母、配偶、居地等
- 支持按世代、行第、姓名、支系排序
- 自动分页并重复表头，同一成员行不得跨页拆开
- 空值统一显示为“—”，过长文本省略或按设置换行
- 支持全谱、支系、世代区间和勾选成员范围

验收标准：2000 人导出无错行、漏人、重复表头异常，列宽与页码正常。

#### 2.11.4 P1-4 关系图谱横向树布局

- 支持“纵向树 / 横向树”即时切换
- 保留现有缩放、平移、折叠、搜索定位及特殊关系展示
- 切换布局不丢失当前选中成员和展开状态
- 布局偏好可按家谱记忆

验收标准：2000 人可见区域操作流畅，切换布局后节点、关系和特殊关系标记正确。

#### 2.11.5 P1-5 关系图谱导出 PNG

- 导出范围：当前视口或当前已展开的可见子图
- 支持 1×、2×、4× 清晰度，白色、宣纸色或透明背景
- 可选图例、谱名、导出时间
- 导出前显示图片尺寸；超过图片引擎限制时提示并建议改用 PDF
- 超大全谱不强制一次性导出，允许先折叠或选择支系

验收标准：导出图片文字清晰、节点和连线完整，中文姓名无乱码。

#### 2.11.6 P1-6 成员查重与合并

- 按“姓名相近 + 出生日期 / 父母 / 配偶”等条件生成疑似重复列表
- 提供两名成员并排对比，由用户选择最终保留的字段
- 合并照片、备注、关系、支系归属和特殊关系
- 合并前展示影响范围，二次确认，事务化执行并支持撤销
- 禁止自动合并，必须人工确认

验收标准：合并后无孤儿关系、无重复关系、无数据丢失，可撤销。

#### 2.11.7 P1-7 Excel 批量导入成员

**目标**：将已有 Excel 成员表批量导入当前家谱，适用于初始建档和补充录入。

**入口与流程**
1. 在「成员录入」页面提供“下载 Excel 导入模板”和“导入 Excel”
2. 选择文件 → 字段映射 → 数据预检 → 错误修正 → 预览确认 → 执行导入 → 结果报告

**文件支持**
- 首期仅支持标准 `.xlsx`
- 不支持 `.xlsm`、宏文件和带外部链接的文件
- 旧版 `.xls` 后续兼容，纳入 P2
- 文件大小、单谱人数等限制在导入前明确提示

**模板字段**

| 字段 | 必填 | 说明 |
|---|---|---|
| 姓名 | 是 | 去除首尾空格 |
| 性别 | 否 | 男 / 女 / 未知 |
| 字 | 否 | 表字 |
| 号 | 否 | 别号 |
| 世代 | 否 | 数字，未填写时尝试推导 |
| 行第 | 否 | 兄弟姐妹排序 |
| 支系 | 否 | 按支系名称匹配 |
| 出生日期 | 否 | 支持 Excel 日期、`1990-05-15`、`1990年5月15日` |
| 出生历法 | 否 | 公历 / 农历，默认公历 |
| 卒日期 | 否 | 同上 |
| 卒历法 | 否 | 公历 / 农历 |
| 在世状态 | 否 | 在世 / 已故 / 未详 |
| 职业 | 否 | 文本 |
| 居地 | 否 | 文本 |
| 葬地 | 否 | 文本 |
| 生平 | 否 | 长文本 |
| 备注 | 否 | 文本 |

模板包含“成员数据”“填写说明”“可选值”三个工作表。首期只导入成员基本信息，不自动挂接父母、配偶、子女关系；照片继续使用现有上传功能。

**字段映射与校验**
- 自动识别标准表头及常见别名；无法识别的列可手动映射或忽略
- 必填字段缺失时阻止导入
- 校验姓名、性别、历法、在世状态、日期、世代、行第、支系名称
- 无法识别的日期标记错误，不自动猜测
- “姓名 + 性别 + 出生日期”完全一致标记疑似重复；仅姓名相同不直接判重
- 重复行可选择跳过、仍作为新成员导入或逐行确认；不允许直接覆盖已有成员

**结果与一致性**
- 支持仅导入校验通过的行，错误行不写入数据库
- 结果页显示总行数、成功数、跳过数、失败数
- 错误报告包含 Excel 行号、字段名、原始值、错误原因和修正建议，可导出为 Excel
- 成功导入的数据作为一个批次记录，支持撤销本次导入
- 导入过程使用事务，异常时可完整回滚；不执行公式、宏、外部链接或脚本

验收标准：标准模板可正确导入 100 人并支持 2000 人规模；错误定位准确；错误行不落库；结果可导出；导入批次可撤销。

### 2.12 P2 详细需求

#### 2.12.1 P2-1 GEDCOM 5.5.1 导入与导出

- 导入支持个人、家庭、事件、日期、地点、备注和照片
- 导入前预检，展示记录数、疑似重复项、不支持标签和乱码风险
- 用户确认后导入，不覆盖现有成员
- 导出时映射成员、关系、日期、照片等标准标签
- 对兼祧、过继等本地扩展关系提供映射说明和兼容性提示

验收标准：标准 GEDCOM 文件可往返导入，无法表达的关系明确提示而非静默丢失。

#### 2.12.2 P2-2 自定义皮肤

- 基于内置皮肤创建自定义主题
- 可调整背景、文字、强调色、边框、状态色和字体
- 实时预览，保存后可按家谱记忆
- 支持主题导入、导出和删除
- 内置皮肤只读；自定义主题异常时回退到内置皮肤
- 主题仅允许颜色和样式配置，不执行任意脚本

#### 2.12.3 P2-3 扇形 / 环形图谱布局

- 以指定成员为中心，支持祖先、后代或全谱范围
- 支持角度、层级间距和节点大小调整
- 特殊关系仍以虚线和文字标注区分
- 布局仅改变视觉位置，不修改世系数据

#### 2.12.4 P2-4 自动更新

- 手动或定期检查 GitHub Releases 新版本
- 显示版本号、发布日期、更新说明和安装包大小
- 下载后校验文件哈希，校验失败不得安装
- 用户确认后安装并重启，不强制更新
- 支持下载暂停、续传和失败重试
- 更新失败时保留旧版本与现有数据

#### 2.12.5 P2-5 Excel 亲属关系导入

- 在 P1 成员导入基础上，支持通过单独工作表导入父母、配偶、子女关系
- 使用稳定标识（成员编号或“姓名 + 性别 + 出生日期”）关联成员
- 支持生 / 养 / 继 / 嗣 / 兼祧父母类型及配偶 subtype
- 导入前展示无法匹配、重复匹配、环路和兼祧主承冲突
- 支持预览、确认、错误报告和批次撤销

验收标准：同名成员不会错误挂接；无法确定的关系必须由用户确认；导入后关系图、统计和 PDF 一致。

#### 2.12.6 P2-6 旧版 `.xls` 文件兼容

- 支持旧版 Excel 97–2003 `.xls` 文件导入
- 与 `.xlsx` 使用同一套字段映射、校验、错误报告和批次撤销流程
- 无法识别的旧格式或加密文件给出明确提示
- 不因兼容 `.xls` 而支持宏文件

## 3. 非功能需求

| 类别 | 指标 |
|---|---|
| 性能 | 单谱 2,000 人量级：列表 / 搜索即时响应；图谱可见区域操作流畅，全谱图按需折叠；Excel 导入有进度提示（设计余量至 1 万人） |
| 启动 | 冷启动 ≤ 3 秒 |
| 数据安全 | WAL + 事务保证一致性；异常退出不丢已提交数据；备份文件完整性校验 |
| 数据隐私 | 完全本地存储，不上传成员数据；云同步未启用 |
| 导入安全 | 不执行 Excel 公式、宏、外部链接或脚本；异常批次可回滚 |
| 易用性 | 全中文界面；录入支持键盘流转；删除类操作可撤销 |
| 兼容性 | Windows 10/11 64 位；导出 PDF 内嵌中文字体 |
| 可维护性 | 数据层 / 业务层 / UI 分离；导出、主题、导入均为独立模块 |
| 交付 | Windows 安装包（NSIS），安装目录可选；自动更新为 P2 |

## 4. 数据模型（当前实现 + P1 扩展）

当前每份家谱一个 SQLite 数据库，核心表如下：

| 表 | 关键字段 |
|---|---|
| meta 家谱元数据 | key, value（谱名、姓氏、堂号、始祖、修谱人等） |
| member 成员 | id(uuid), name, gender, generation, branch_id, birth_date, birth_lunar, death_date, death_lunar, alive, birth_order, courtesy_name, title, occupation, residence, burial, biography, photo_path, deleted, delete_batch, created_at, updated_at |
| relation 关系 | id, type(parent_child / spouse), subtype(生/养/继/嗣/兼祧、原配/继配), from_id, to_id, is_primary(兼祧主承标记), note, deleted, delete_batch, created_at, updated_at |
| generation_char 字辈 | id, branch_id(可空=全谱), generation, char, note |
| branch 支系 | id, name, parent_id, founder_id, note, deleted, created_at |
| change_log 变更日志 | seq, entity, entity_id, op, payload, created_at |

外部文件：
- `registry.json`：数据目录下的家谱注册表
- `config.json`：用户数据目录下的全局设置（数据目录、皮肤、自动备份等）
- `photos/`：每份家谱的本地照片目录

P1 Excel 导入计划扩展：

| 表 | 用途 |
|---|---|
| import_batch | 导入批次：来源文件、哈希、状态、总数、成功数、失败数、创建时间 |
| import_issue | 导入问题：批次、Excel 行号、字段、原始值、错误原因 |

关系说明：
- 过继成员同时存在本生父母（subtype=生）与嗣父母（subtype=嗣）两组 parent_child 记录
- 兼祧成员存在主承父系（is_primary=1）与兼祧父系（subtype=兼祧, is_primary=0）记录，图谱 / PDF 均双系呈现

## 5. 技术方案（当前实现）

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面框架 | **Electron 45** | 主进程负责数据、文件、PDF 和窗口管理 |
| 前端 | **Vue 3.5 + TypeScript 5.9 + Vite 8** | electron-vite 6 构建 |
| 本地数据库 | **node:sqlite（Electron 内置）** | 同步 API、事务、WAL，零原生依赖 |
| 关系图谱 | **自研 SVG 世系树布局** | `src/graph/layout.ts`，支持纵向树、折叠、祖先 / 后代范围；不再使用 AntV G6 |
| PDF 导出 | **pdf-lib + @pdf-lib/fontkit** | 矢量输出、内嵌 CJK 子集字体；不再依赖 Electron printToPDF |
| 农历 | **lunar-typescript** | 公农历互转、干支纪年 |
| 备份 | **adm-zip** | ZIP 快照、清单和完整性校验 |
| Excel 导入 | **ExcelJS 4.4** | 主进程解析 `.xlsx`，模板、字段映射、预检、事务导入、问题报告与批次撤销 |
| GEDCOM 交换 | **GEDCOM 5.5 / 5.5.1 + iconv-lite** | 主进程解析与生成 `.ged`，预检、重复确认、兼容标签、UTF-8/GBK、照片与批次撤销 |
| 打包 | **electron-builder 26（NSIS）** | 非一键安装，允许选择安装目录 |
